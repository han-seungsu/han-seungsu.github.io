# Seungsu Han — Academic Website

A lightweight, multi-page academic website designed for GitHub Pages.

## Pages

- `index.html`: home page
- `research.html`: research projects and directions
- `publications.html`: publications, talks, posters, and honors
- `CV_SeungsuHan.pdf`: CV link target
- `assets/profile.jpg`: profile photo
- `assets/style.css`: all design styles
- `assets/script.js`: mobile navigation and automatic footer year

## Before publishing

1. Copy your CV into the project root and name it `CV_SeungsuHan.pdf`.
2. Copy a portrait photo to `assets/profile.jpg`.
3. Replace the GitHub link in `index.html` with your actual GitHub profile URL.
4. Check names, dates, paper status, and contact information.
5. Keep or remove the Google Fonts links. The site falls back to system fonts if they are unavailable.

## Publish on GitHub Pages

1. Create a public repository named `<your-github-username>.github.io`.
2. Upload these files to the root of the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. The site will appear at `https://<your-github-username>.github.io/`.

No Jekyll, Ruby, Node.js, or build command is required.
